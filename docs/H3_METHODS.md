# H3 analysis and limits

The preregistered operational contrast in `Analysis/h3_plan/analysiere_h3.py` equally weights within-medoid differences in PA proportions between supportive and non-supportive simulated contexts, then summarizes over six seed-based replications. Technical fallback days are excluded, subject to the documented quality threshold. The original four-medoid contrast was **not estimable**: one medoid lacks one context category in five of six replications. This is not evidence for or against the original hypothesis.

Subsequent analyses were exploratory, including a restricted within-medoid analysis of C1?C3 and an alternative pooled run-level context contrast, sign test, and Friedman comparison across fixed medoids. These have different estimands. The six runs?not individual days?are inferential units; fixed empirically selected medoids do not constitute a random population sample. The contexts are not randomized and findings are not causal. Days without downtime remain part of the pooled final analysis; no separate downtime sensitivity is required for that analysis. The historic prespecified analysis file retains its own originally planned sensitivity calculation.

No H3 day-level data, medoid-by-run outcomes, or pooled run counts are included because the latter can still permit inference about one of four empirical profiles. Consequently none of these inferential results or H3 figures can be independently reproduced from this public package alone. `reproducibility/reproduce_restricted.py` accepts separately authorized data and reproduces the pooled analysis and Friedman calculation without simulations or LLM calls; the original fixed analysis requires separately authorized traces, context inputs, persona mapping and manifests. `Analysis/h3_plan/replikationen.json` documents seeds and settings only. The `hindering` publication label refers to the entire binary `non_supportive` class, including neutral days; it does not change the classifier.
